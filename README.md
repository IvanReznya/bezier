# Триангуляция Делоне

C++17, Qt Widgets 5.15/6.x и CMake. Проект открывается независимо от остальных папок.

## Запуск

Откройте CMakeLists.txt из этой папки в Qt Creator, выберите Desktop Qt Kit и нажмите Run.

Сборка в терминале:

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH="/путь/к/Qt/ваш_комплект"
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
```

Для проверки только алгоритмов можно собрать отдельный каталог с параметром `-DBUILD_GUI=OFF`.

## Управление

Клики добавляют точки, кнопка строит триангуляцию. Треугольники фиолетовые; галочка показывает описанные окружности. Поддерживаются перетаскивание и онлайн-пересчёт.

## Ограничения

Используется long double и относительный допуск для проверки окружности. Точки на одной окружности допускают неоднозначный ответ. Учебный алгоритм с перебором рассчитан на небольшие интерактивные наборы; это не точное решение для любых почти вырожденных данных.
