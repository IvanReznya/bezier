# Кривые Безье

C++17, Qt Widgets 5.15/6.x и CMake. Проект открывается независимо от остальных папок.

## Запуск

Откройте CMakeLists.txt из этой папки в Qt Creator, выберите Desktop Qt Kit и нажмите Run.

Сборка в терминале:

```sh
cmake -S . -B build -DCMAKE_PREFIX_PATH="/путь/к/Qt/ваш_комплект"
cmake --build build --config Debug
ctest --test-dir build -C Debug --output-on-failure
```

Для проверки только алгоритмов можно собрать отдельный каталог с параметром `-DBUILD_GUI=OFF`.

## Управление

Клики добавляют контрольные точки, их можно перетаскивать. Одновременно видны квадратичная, кубическая и общая кривые. Ползунок t и галочка показывают построение де Кастельжо.

## Ограничения

Кривые вычисляются по конечной выборке из 301 точки. Для сравнения степеней нужно хотя бы четыре контрольные точки; для трёх различных степеней — пять.
